Little Office | Interactive 3D web page

Why the earlier version couldn't be moved
The Godot version is a fixed-camera desktop demo with no mouse control. This one is a real WebGL 3D model in the browser, not a 2D screenshot.
You can inspect the model: rotate, zoom, pan, reset and auto-rotate. Characters are still static (no walking or waving); paper pick-up hasn't been ported yet.

How to open it
Live: https://dormathon-banjir-productivity.vercel.app
Locally: run python app.py from the repo root and open http://127.0.0.1:5000 (it redirects to /web-office/).
app.py serves both this page and the /api/run endpoint the "Run" button calls.
You can't double-click index.html: the local GLB and ES modules must be loaded over HTTP.
Don't copy index.html on its own; keep the whole web-office folder, including assets, vendor, styles.css and app.js.
All models and rendering libraries are local files; viewing the page needs no cloud service or API key.

Mouse and touch controls
1. Left-drag on the office: orbit around it.
2. Scroll wheel or two-finger trackpad scroll: zoom.
3. Right-drag, or Shift + left-drag: pan the camera.
4. ＋ and − at the top right: zoom; "Reset view": back to the starting front angle.
5. "Auto-rotate": slow orbit; click again to stop.
6. Touch: one-finger drag rotates, two-finger pinch zooms / pans.
7. After clicking the 3D view: arrow keys rotate, plus/minus zoom, R resets.
The model is a dollhouse open on two sides; orbiting behind a wall shows its back face. That's normal 3D geometry, not the model disappearing.

Running the agents
Type a goal in the bar at the bottom of the scene and click "Run".
The page calls POST /api/run, which runs Secretary, Logistics and Financial; the cards show record, exception and task counts when it finishes.
The full result is in the browser console as lastRun.
Character walking needs animation / rigging; rotating the view doesn't make them walk, and this isn't done yet.

Files
index.html: page structure, the in-scene input bar, side panels and the three agent cards.
styles.css: warm UI and narrow-screen layout.
app.js: GLB loading, camera controls, and the /api/run call.
assets/office.glb: the same office model, unmodified.
vendor: Three.js 0.180.0 with OrbitControls and GLTFLoader, local copies including the MIT licence.
browser-acceptance-results.json: automated browser interaction check.

Model and rendering
Uses the GLB from the Godot project (858 meshes). WebGL lighting won't match Blender/Cycles pixel for pixel; the original .blend and Godot files are unchanged.
