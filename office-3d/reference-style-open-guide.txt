Office, reference-style layout · Stage 01 (characters are still seated placeholders)

Goal of this round
An office with separate desks, chairs and computers for the boss and the assistant, not a copy of the piano living room in the reference.
Match the reference as closely as practical: green wall panels, honey-coloured parquet, rounded furniture, cream trim, soft daylight and a dollhouse composition.
A single reference image doesn't show hidden structure or exact sizes, so this does not claim a strict 1:1 geometry or lighting match.
As agreed: check the layout first, then add facial features, hair, clothing and hands.

Files
- office-reference-layout.blend: editable revised layout scene.
- office-reference-layout-preview.png: actual Blender render preview, 1600×1200 (4:3).
- build_office_reference.py: script that regenerates this version.
- reference-style-open-guide.txt: this guide.
The previous office-blockout.blend and build_office.py are kept, not overwritten.

Opening
Blender > File > Open > select office-reference-layout.blend.
Made and verified with Blender 5.4.0 Alpha; other versions have not been tested.
No add-ons or external textures needed.
Numpad 0 for the main camera; without a numpad: View > Cameras > Active Camera.
F12 to re-render (some Mac keyboards need Fn + F12).
The main camera is a slightly top-down, front-angled orthographic layout view like the reference, not an eye-level photo view.
This round uses 4:3 to compare with the reference; change the ratio in Output Properties and reframe if needed.

Changing the layout
In the Outliner select Boss_ROOT / move entire workstation, press G, then X/Y to move.
Same for Assistant_ROOT / move entire workstation.
Desk, chair, computer and seated placeholder follow the root object.
Press N for the Item panel to type exact position, rotation or scale.
To change one piece of furniture, expand its collection and select the mesh.
Tab for Edit Mode; Bevel modifiers are kept so you can adjust the rounding.
Select BOOKCASE_ROOT for the bookcase; the window is in the 05_Window collection.
The star garland on the wall is in 06_Plants_Props; hide it or edit it separately.

Collections
01_Room: two walls, base, herringbone parquet, shared blue-grey rug.
02_Boss_Workstation: boss desk and chair, computer, paper, files, notebook.
03_Assistant_Workstation: assistant desk and chair, computer, paper, files, notebook.
04_Bookcase: bookcase, books and storage boxes.
05_Window: window frame, sill, pale window insert, placeholder curtains.
06_Plants_Props: potted plants and star garland.
07_Pose_Placeholders: faceless seated placeholders, not the final characters.
08_Cameras: main camera and a low-angle backup camera.
09_Preview_Lights: basic preview lights, not the final lighting design.
10_Studio_Ground: outer studio background floor.

Changing it by script
Open build_office_reference.py in Blender's Scripting workspace.
Edit ROOM_WIDTH / ROOM_DEPTH, both desk positions, desk sizes, camera and render settings at the top.
Run Script clears the current scene and overwrites the revised outputs with the same name.
Use File > Save As first; don't re-run on an unsaved scene.
The script writes to its own folder.
You can edit the .blend normally without running the script.

What to check
1. Size, spacing and front/back relationship of the boss's large desk and the assistant's small desk.
2. Whether each placeholder figure sits in its own chair at its own desk.
3. Whether the bookcase, window, plants and walking space are sensibly placed.
4. Whether the camera shows the whole office and both workstations.
5. Whether the compact dollhouse proportions and base colours are heading the way you want.

Once these are confirmed, add real wood and fabric materials, glass, refined lighting and cartoon characters.
No animation rig, no detailed characters, and the web frontend was not modified or connected.
