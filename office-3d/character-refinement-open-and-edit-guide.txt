办公室人物细化版｜本轮只替换老板与助理

一、先打开哪个文件
在 Blender 中选择 File（文件）→ Open（打开），打开 office-character-detail.blend。
不需要运行脚本，不需要安装插件或下载贴图。
本机制作与验证环境：Blender 5.4.0 Alpha。其他版本未实际验证。

二、查看与运行
1. 小键盘 0：切到原办公室主镜头；没有小键盘时用 View → Cameras → Active Camera。
2. F12：使用原相机、原灯光重新渲染 1600×1200 全景。
3. 中键拖动旋转，滚轮缩放，Shift＋中键平移。
4. 修改后用 File → Save As 另存文件，避免覆盖认可的布局原稿。

三、本轮修改的内容
男性老板参考 IMG_6500.JPG：圆润大头、近黑短发和侧分斜刘海、粗黑眉、黑点眼、桃肤色与柔和腮红、小玫红三角鼻、细红横嘴、深灰蓝西装、白衬衫与蓝领带。
女性助理参考 IMG_6499.JPG：深棕近黑齐肩侧分发、棕色眉、黑眼睛与小睫毛、桃肤色与柔和腮红、小鼻和细红横嘴、深灰蓝西装与白衬衫，无领带。
两人均有耳廓、西装翻领及口袋边、袖口、纽扣、布料微纹理、弯曲坐姿裤腿、鞋底与鞋面缝线、独立手指、拇指和细小指甲，一只手握灰色笔。
原座位和工位父子关系保留。本次为静态可编辑人物，不含骨骼、动作动画或自动表情。
二维图仅提供正面可见形象；侧面、背面和立体比例是据此设计，不能视为严格几何 1:1 复原。
为了保留办公室内的原坐姿，持笔手没有移到桌上原交互纸张的位置；桌上纸张、键盘和原有笔均未挪动。

四、确认其他东西没有更改
原稿 office-reference-layout.blend 保留，未覆盖，也未重跑房间生成脚本。
645 个非人物对象、31 个原有材质、10 个集合、相机、灯光、世界环境、房间地板、星星挂绳、桌椅、电脑、书架、窗户和桌上物件均做了保存前后及重新打开比对。
检查结果在 character-refinement-scene-consistency-check.json；protected_changes 应为空数组。
渲染输出路径更换为新版预览文件；画幅、采样、色彩管理、主相机和照明参数保持原值。
人物体积和材质改变后产生的新投影、遮挡和反射属于正常渲染变化，不代表调整了家具或灯光。

五、人物怎么找、怎么修改
在右上角 Outliner 展开 07_Pose_Placeholders（沿用原集合名称，里面已替换为细化人物）。
老板总节点：Boss_POSE_ROOT / seated blockout only。
助理总节点：Assistant_POSE_ROOT / seated blockout only。
为保持根节点与验证一致，沿用旧名字，但人物不再是无五官占位。
子对象前缀分别是 Boss character / 和 Assistant character /。
round face with soft chin：脸。
short swept side-part hair cap：老板短发。
shoulder length side-part bob：助理齐肩发。
tailored jacket body：西装身体。
notched suit lapel：翻领。
blue tie knot / blue tie blade：老板领带。
gray pen held in writing hand：人物手持笔。
选中某个部件，小键盘 .（句号）：把视口聚焦到该部件。
选中人物根节点按 G，可移动整个人物；选中 Boss_ROOT 或 Assistant_ROOT 则移动整套工位，包括桌椅人物。
材质名称以 Character / 开头，修改这些不会改动房间或家具的 Preview / 材质。

七、仅在需要重建人物时运行脚本
一般直接打开 .blend 即可。脚本是可选的。
将 refine_office_characters.py 与 office-reference-layout.blend 放在同一目录。
终端命令（macOS）：
"/Applications/Blender.app/Contents/MacOS/Blender" --background --python-exit-code 1 --python "/完整路径/refine_office_characters.py" -- --refine
不要把 /完整路径 当作真实路径；替换成脚本实际位置。
这会读取布局基准，重新生成 office-character-detail.blend 和全景，覆盖同名新版输出；不会覆盖布局基准。
不要在已有未保存修改的 Blender 窗口运行该脚本；它会加载布局基准并替换当前场景。先另存自己的修改。
