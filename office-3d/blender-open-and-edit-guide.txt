Little Office · Blender base model (stage 01)

Files in this delivery
1. office-blockout.blend: editable native Blender scene.
2. office-blockout-preview.png: layout preview rendered from that scene.
3. build_office.py: script that rebuilds the base scene.
4. blender-open-and-edit-guide.txt: this guide.

1. Opening
In Blender choose File > Open and select office-blockout.blend.
No add-ons and no external textures are needed.
Made with Blender 5.4.0 Alpha; open it with that version or a later compatible one.

2. Camera and rendering
Numpad 0: switch to the preset front-angled layout camera.
No numpad: top menu View > Cameras > Active Camera.
Middle-mouse drag: orbit the model; scroll wheel: zoom.
F12: re-render; some Mac keyboards need Fn + F12.
Currently Cycles CPU, 64 samples, denoised, 1600×900 (16:9).
Actual render time depends on the machine.

3. Moving a whole workstation
In the Outliner (top right), find and select these Empty root objects:
Boss_ROOT / move entire workstation: the boss's full workstation.
Assistant_ROOT / move entire workstation: the assistant's full workstation.
Press G to move, then X or Y to lock the axis; R rotates, S scales.
Desk, computer, chair and seated placeholder all follow the root object.
To move a single component, select it inside its collection.
Press N to open the Item panel on the right and type Location / Rotation / Scale directly.
When moving or scaling a placeholder figure, select its POSE_ROOT, not a single leg.

4. Editing furniture and the room
Every component is a separate native mesh; select it and press Tab for Edit Mode.
Bevel modifiers are kept; adjust the rounding width in the modifier panel.
The window opening in the left wall is built from separate wall blocks; the frame and sill are modelled separately.
The scene uses metric units.
Collections:
01_Room: floor, wall panels, rug.
02_Boss_Workstation: boss desk, computer, documents and chair.
03_Assistant_Workstation: assistant desk, computer, documents and chair.
04_Bookcase: bookcase, blank books and storage boxes.
05_Window: window frame, sill, placeholder curtains and a pale window insert.
06_Plants_Props: simple plants and a blank picture.
07_Pose_Placeholders: seated placeholders, not the final cartoon characters.
08_Cameras: main layout camera and a lower-angle second camera.
09_Preview_Lights: soft lights for the stage 01 preview only.
10_Studio_Ground: studio background floor; hide this collection if not needed.

5. Changing the layout by script
Save your .blend under a new name first: re-running the script clears the current scene and discards unsaved changes.
Blender > Scripting > Text Editor > Open, and open build_office.py.
Edit the values at the top: ROOM_WIDTH, ROOM_DEPTH, BOSS_DESK_POSITION,
ASSISTANT_DESK_POSITION, BOSS_DESK_SIZE, ASSISTANT_DESK_SIZE,
CAMERA_POSITION, CAMERA_TARGET, RENDER_SIZE, etc.
Run it with the Text Editor's Run Script button.
Or from a terminal:
"/Applications/Blender.app/Contents/MacOS/Blender" --background --python "/full/path/build_office.py"
The script writes the .blend and preview PNG to its own folder, overwriting outputs with the same name.

6. What to review in this round
Overall room proportions, size and spacing of the two desks, chairs and seated poses,
computer placement, bookcase and window placement, and whether the front-angled camera shows the layout clearly.
Sage green, warm wood and soft light close to the reference image are provided as a preview base.
The wood floor is simple geometric tiles with base colours, not final textures;
the window is a pale insert, not final transmissive glass; the figures are placeholder geometry with no faces, hair, clothes or rigging.
Detailed materials, lighting and simplified cartoon characters come after the layout is approved.
This round did not modify or connect the web frontend, and has no API or real accounting features.
